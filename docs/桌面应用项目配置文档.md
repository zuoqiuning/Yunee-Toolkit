## 二、环境准备

### 2.1 确认现有环境版本

在命令行中执行以下命令，确认版本正确：

```bash
node -v        # 应显示 v26.8.1
git --version  # 应显示 git version 2.53.0.windows.1
```

### 2.2 安装 pnpm（全局）

pnpm 比 npm 更快、更省磁盘空间，且能更好地处理 monorepo 和依赖提升问题。

```bash
# 使用 npm 全局安装 pnpm
npm install -g pnpm

# 验证安装
pnpm -v
```

### 2.3 配置 pnpm 国内镜像加速

为了提升依赖下载速度，配置淘宝镜像源：

```bash
# 设置 pnpm 全局镜像源为淘宝镜像
pnpm config set registry https://registry.npmmirror.com

# 验证配置
pnpm config get registry
```

### 2.4 创建 `.npmrc` 文件（解决 Electron 兼容性）

在项目根目录创建 `.npmrc` 文件，写入以下内容。这是**解决 pnpm 与 Electron 原生模块兼容性问题**的关键配置：

```ini
# 解决原生模块（如 better-sqlite3、Electron 自身）的兼容问题
shamefully-hoist=true

# 自动安装对等依赖
auto-install-peers=true

# 忽略严格的对等依赖检查（避免安装时的警告和错误）
strict-peer-dependencies=false

# 设置 Electron 镜像源（加速 Electron 下载）
electron_mirror=https://npmmirror.com/mirrors/electron/

# 设置 Electron 构建工具镜像源
electron_builder_binaries_mirror=https://npmmirror.com/mirrors/electron-builder-binaries/
```

> **安装时间提示**：首次 `pnpm install` 由于需要下载 Electron（约 80MB）和 better-sqlite3（含预编译二进制文件），可能需要 3-5 分钟，属于正常现象。已在 `.npmrc` 中配置镜像加速，请耐心等待。

## 四、UI 组件库安装与配置

### 4.1 安装 Arco Design Vue

```bash
# 安装 Arco Design 核心库
pnpm add @arco-design/web-vue@2.58.2
```

**兼容性确认**：
- Arco Design Vue `2.58.2` 要求 Vue `>=3.0.0`，你的 `3.5.41` 完全满足。
- Arco 对 Node.js 版本要求 `>=14.x`，你的 `26.8.1` 完全满足。

### 4.2 安装按需加载插件（关键步骤）

按需加载是减小打包体积的关键，使用 Arco 时同样建议开启。

```bash
# 安装按需加载插件（开发依赖）
pnpm add -D unplugin-vue-components@0.27.4
pnpm add -D unplugin-auto-import@0.18.3
```

### 4.3 配置 Vite 插件（关键步骤）

编辑项目根目录的 `vite.config.ts` 文件，完整配置如下：

```typescript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import Components from 'unplugin-vue-components/vite'
import AutoImport from 'unplugin-auto-import/vite'
import { ArcoResolver } from 'unplugin-vue-components/resolvers'

export default defineConfig({
  plugins: [
    vue(),
    
    // 自动导入 Vue 相关 API（ref, reactive, computed 等）
    AutoImport({
      imports: ['vue', 'vue-router', 'pinia'],
      dts: 'src/auto-imports.d.ts', // 生成类型声明文件
    }),
    
    // 按需自动导入 Arco 组件
    Components({
      resolvers: [
        // 字节 Arco Design 解析器
        ArcoResolver({
          sideEffect: true  // 自动引入组件样式
        })
      ],
      dts: 'src/types/components.d.ts', // 生成组件类型声明文件
    })
  ]
})
```

### 4.4 在 `main.ts` 中引入样式文件

编辑 `src/main.ts` 文件，引入 Arco 的全局样式：

```typescript
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import App from './App.vue'
import router from './router'

// 引入 Arco Design 全局样式
import '@arco-design/web-vue/dist/arco.css'

const app = createApp(App)

app.use(createPinia())
app.use(router)
app.mount('#app')
```

### 4.5 UI 组件使用示例

配置完成后，在 Vue 组件中可以直接使用 Arco 组件，前缀为 `a-`，无需手动 `import`：

```vue
<template>
  <div>
    <!-- Arco 组件，前缀为 a- -->
    <a-button type="primary">Arco 按钮</a-button>
  </div>
</template>

<script setup lang="ts">
// ref、reactive 等 API 也会自动导入，无需手动 import
const count = ref(0)
</script>
```

### 5.3 创建 Electron 主进程文件

在项目根目录创建 `electron-main.js`：

```javascript
const { app, BrowserWindow } = require('electron')
const path = require('path')

function createWindow() {
  const win = new BrowserWindow({
    width: 1200,
    height: 800,
    webPreferences: {
      // 关键安全配置
      contextIsolation: true,    // 必须开启
      nodeIntegration: false,   // 必须关闭
      sandbox: true,            // 推荐开启
      preload: path.join(__dirname, 'preload.js') // 预加载脚本
    }
  })

  // 开发环境加载 Vite 开发服务器
  if (process.env.NODE_ENV === 'development') {
    win.loadURL('http://localhost:5173')
    win.webContents.openDevTools()
  } else {
    // 生产环境加载打包后的文件
    win.loadFile(path.join(__dirname, 'dist/index.html'))
  }
}

app.whenReady().then(createWindow)

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') {
    app.quit()
  }
})
```

创建 `preload.js` 预加载脚本：

```javascript
const { contextBridge, ipcRenderer } = require('electron')

// 通过 contextBridge 安全地暴露 API 给渲染进程
contextBridge.exposeInMainWorld('electronAPI', {
  // 示例：向主进程发送消息
  sendMessage: (channel, data) => {
    ipcRenderer.send(channel, data)
  },
  // 示例：调用主进程并等待返回
  invoke: (channel, data) => {
    return ipcRenderer.invoke(channel, data)
  }
})
```

### 5.4 配置 `package.json` 打包脚本

在 `package.json` 中添加以下字段：

```json
{
  "main": "electron-main.js",
  "scripts": {
    "dev": "vite",
    "build": "vue-tsc && vite build",
    "preview": "vite preview",
    "electron:dev": "NODE_ENV=development electron .",
    "electron:build": "pnpm build && electron-builder"
  },
  "build": {
    "appId": "com.yourcompany.yourapp",
    "productName": "我的应用",
    "directories": {
      "output": "release"
    },
    "win": {
      "target": "nsis",
      "icon": "build/icon.ico"
    },
    "nsis": {
      "oneClick": false,
      "allowToChangeInstallationDirectory": true
    },
    "files": [
      "dist/**/*",
      "electron-main.js",
      "preload.js"
    ],
    "asarUnpack": [
      "node_modules/better-sqlite3/**/*"
    ]
  }
}
```

> **图标文件说明**：Windows 打包需要 `.ico` 格式图标，建议尺寸 256x256。可使用 `icoconvert` 或在线工具将 PNG 转换为 ICO 格式。如果暂时没有图标，可以**先注释掉 `icon` 配置行**，不影响打包。

### 5.5 开发体验优化

如果需要 Electron 主进程代码修改后自动重启，可以安装 `nodemon`：

```bash

```

然后添加脚本到 `package.json`：

```json

```

> **注意**：**渲染进程（Vue）的热更新**由 Vite 原生支持，无需额外配置。

## 七、打包体积优化说明

### 7.1 按需加载的工作原理

`unplugin-vue-components` 和 `unplugin-auto-import` 的作用是：

- **只打包使用到的组件**：在代码中写 `<a-button>`，插件才会自动 import `Arco` 的 `Button` 组件，**不会打包整个 Arco 库**。
- **效果**：如果只用了 8 个 Arco 组件，打包体积从完整库的 **~1.5MB+**，下降到只包含这 8 个组件的 **~200KB**。

### 7.2 进一步优化建议

1. **使用 `vite build --report` 分析打包体积**
   ```bash
   pnpm build -- --report
   ```

2. **移除未使用的依赖**
   ```bash
   pnpm remove <package-name>
   ```

3. **开启 Vite 的代码分割**
   ```typescript
   // vite.config.ts
   export default defineConfig({
     build: {
       rollupOptions: {
         output: {
           manualChunks: {
             'arco': ['@arco-design/web-vue']
           }
         }
       }
     }
   })
   ```

4. **使用轻量级图标方案**
   - 避免直接导入整个图标库，使用 `@arco-design/web-vue/icon` 的按需导入方式。

## 九、常见问题排查

### 问题 1：Electron 打包后 `better-sqlite3` 报错

**错误现象**：`Error: Cannot find module 'better-sqlite3'`

**解决方案**：检查 `package.json` 中的 `asarUnpack` 配置是否包含 `better-sqlite3`：

```json
"asarUnpack": [
  "node_modules/better-sqlite3/**/*"
]
```

### 问题 2：UI 组件库样式不生效

**错误现象**：组件显示但无样式

**解决方案**：
1. 确认 `vite.config.ts` 中的 `ArcoResolver` 配置正确。
2. 确认 `main.ts` 中导入了 Arco 的 CSS 文件。
3. 清除浏览器缓存或重启开发服务器。

### 问题 3：pnpm 安装时提示“对等依赖冲突”

**错误现象**：`peer dependencies conflict`

**解决方案**：已通过 `.npmrc` 中的 `strict-peer-dependencies=false` 和 `auto-install-peers=true` 解决。

### 问题 4：Electron 启动后白屏

**错误现象**：Electron 窗口打开但为空白

**解决方案**：
1. 确认 Vite 开发服务器已启动（`pnpm dev`）。
2. 确认 `electron-main.js` 中的 `loadURL` 地址为 `http://localhost:5173`。
3. 检查浏览器控制台是否有报错。

### 问题 5：pnpm 与 npm 混用导致的问题

**错误现象**：`node_modules` 结构混乱、`lock` 文件冲突

**解决方案**：
```bash
# 删除 node_modules 和所有 lock 文件
rm -rf node_modules pnpm-lock.yaml package-lock.json

# 重新用 pnpm 安装
pnpm install
```

> **⚠️ 重要**：项目统一使用 `pnpm`，不要混用 `npm` 或 `yarn` 安装依赖。混用可能导致 `node_modules` 结构混乱和 `lock` 文件冲突。
