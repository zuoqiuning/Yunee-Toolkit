## 开发注意点

---

### 🏗️ 架构与进程管理：打好地基

Electron 应用由主进程、渲染进程和预加载脚本构成。

*   **各司其职，严守边界**：
    *   **主进程 (Main)**：是应用入口，**只做**窗口管理、IPC 处理和应用生命周期控制。**绝对不要**在主进程执行 CPU 密集型任务，否则会卡死整个应用。像调用 FFmpeg 这类耗时操作，应放在主进程或单独的 Utility Process 中处理。
    *   **渲染进程 (Renderer)**：**只负责 UI 界面**，类似浏览器环境，**不应**直接访问 Node.js 或文件系统。你的 Vue 应用就在这里运行。
    *   **预加载脚本 (Preload)**：是主进程和渲染进程之间的“安检通道”，用于安全地暴露有限的 API 给渲染进程。

*   **启动顺序的时序问题**：带本地数据库的项目，启动流程要格外注意顺序。必须**先**完成数据库初始化，**再**创建应用窗口和执行其他业务逻辑。用 `async/await` 来严格控制异步流程。

### 🔒 安全第一：不可妥协的底线

安全是 Electron 开发的重中之重，必须从项目一开始就建立正确的安全配置。

*   **核心安全配置 (必须设置)**：创建 `BrowserWindow` 时，务必包含以下配置：
    *   `contextIsolation: true`：隔离渲染进程和预加载脚本的上下文，**非协商的底线**。
    *   `nodeIntegration: false`：禁止渲染进程直接访问 Node.js API。
    *   `sandbox: true`：为渲染进程启用操作系统级别的沙箱。

*   **安全的 IPC 通信模式**：
    *   **正确做法**：在预加载脚本中，通过 `contextBridge` 暴露**经过严格封装**的 API。**只暴露**方法，不暴露任何对象或 `ipcRenderer` 本身。
    *   **双向通信**：推荐使用 `ipcMain.handle` + `ipcRenderer.invoke` 模式。它返回 Promise，支持 `async/await`，错误处理也更优雅。
    *   **单向通信**：使用 `ipcMain.on` + `ipcRenderer.send`。
    *   **参数校验**：在主进程的 IPC 处理器中，**必须对所有来自渲染进程的参数进行严格校验**，防止恶意输入。

### ⚡️ 性能优化：让应用轻快起来

Electron 应用常因体积大、内存占用高而被人诟病，需要从源头进行优化。

*   **应用启动速度**：
    *   **延迟加载**：非首屏必需的模块，使用 `import()` 动态导入。
    *   **减少依赖**：审视 `package.json`，移除无用依赖。用轻量库替代重型库（如用 `date-fns` 替代 `moment.js`）。
    *   **骨架屏**：在 Vue 应用加载时，先显示一个简单的骨架屏，能有效改善用户对启动速度的感知。

*   **内存与包体积**：
    *   **依赖分析与去重**：使用 `webpack-bundle-analyzer` 等工具分析打包体积。确保依赖树扁平化，移除重复依赖。
    *   **按需加载**：使用支持按需引入的 UI 库（如 Element Plus）。
    *   **生产与开发依赖分离**：`devDependencies` 中的包不会被打包进最终应用。

### 📦 打包与分发：临门一脚的学问

*   **使用 `electron-builder`**：这是目前最主流、功能最全的打包工具。
*   **路径与资源问题**：代码中**始终使用相对路径**引用静态资源，避免打包后白屏。集成 FFmpeg 等二进制文件时，要配置 `asarUnpack`，将其排除在 `app.asar` 之外。
*   **平台特定配置**：
    *   **Windows**：图标必须为 `.ico` 格式。配置 `nsis` 选项以定制安装包行为。
    *   **代码签名**：正式发布的应用必须进行代码签名。Windows 可用 `electron-builder` 的 `win.certificateFile` 配置。

### 🔄 自动更新：让用户永远用最新版

*   **使用 `electron-updater`**：这是与 `electron-builder` 配合最顺畅的方案。
*   **配置更新源**：在 `package.json` 的 `build.publish` 中配置更新服务器 URL。
*   **实现更新逻辑**：在主进程中监听 `autoUpdater` 的事件（如 `checking-for-update`, `update-downloaded`），并在下载完成后调用 `quitAndInstall()`。

### 🎬 集成 FFmpeg 专项注意事项

集成 FFmpeg 这类原生工具，打包和调用有两处关键“陷阱”需要注意。

*   **打包时排除 ASAR**：`electron-builder` 默认会将代码打包进 `app.asar`。但 FFmpeg 是可执行文件，不能放在里面。必须在 `build` 配置中用 `asarUnpack` 将其排除。
*   **正确处理路径**：打包后，文件路径会变。推荐使用 `process.resourcesPath` 来定位资源目录。

---

### 💎 总结

把这几个核心方面（**严守进程边界、落实安全配置、持续关注性能、细致处理打包**）处理好，你的 Electron 应用就能在保持开发效率的同时，拥有良好的稳定性、安全性和用户体验。开发过程中多参考官方文档和社区最佳实践，可以避免不少弯路。
